# CodeAlpha_StockTradingPlatform

A simulated stock trading console application built using Java as part of the CodeAlpha Java Programming Internship. It models an interactive investment environment allowing users to buy and sell stocks with dynamic price fluctuations and persistent portfolio tracking.

## Features
- **Market Simulation**: Live stock watch with simulated real-time price fluctuations[cite: 1].
- **Trading Operations**: Buy and sell shares with automatic wallet deduction/addition and quantity validation[cite: 1].
- **Portfolio Tracking**: Real-time evaluation of cash balance, held assets, and overall account value[cite: 1].
- **Transaction History**: Detailed audit trail of all completed buy and sell orders[cite: 1].
- **File Persistence**: Automatically exports and saves account balances and holdings to a local file (`portfolio.txt`)[cite: 1].

## Tech Stack
- **Language**: Java (JDK 8 or higher)
- **Concepts**: Object-Oriented Programming (OOP), HashMaps/LinkedHashMaps, Java File I/O (`PrintWriter`, `FileWriter`), Exception Handling
