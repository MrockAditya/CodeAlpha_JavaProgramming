# CodeAlpha_StudentGradeTracker

A console-based Java application developed as part of the CodeAlpha Java Programming Internship to input, compute, and analyze student academic performance.

## Features
- **Student Data Management**: Add students along with multiple subject marks using Java collections (`ArrayList`).
- **Grade Analytics**: Automatically calculates individual student averages, total class average, and identifies the highest and lowest scores.
- **Summary Report**: Displays an aligned tabular performance overview of all students.

## Tech Stack
- **Language**: Java (JDK 8 or higher)
- **Concepts**: Object-Oriented Programming (OOP), ArrayLists, Scanner I/O, Formatted Output
